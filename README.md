# 🚗 Tesla Stock Price Prediction

Deep Learning project comparing SimpleRNN vs LSTM for TSLA stock forecasting.

## Results
| Model | RMSE | MAE | MAPE | R² |
|-------|------|-----|------|----|
| SimpleRNN | $41.78 | $22.16 | 6.56% | 0.66 |
| LSTM | $46.45 | $29.34 | 8.53% | 0.58 |
